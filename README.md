# Otodom Demo Build

Standalone replica of the Staging Otodom widget demo. Same app, listings, and ReimagineHome staging widget integration — separate folder, GitHub repo, and Vercel project from the original `stage-otodom-widget` build.

## Scripts

- `npm run dev` — local Vite server on port 5180
- `npm run build` — sync listing images and production build
- `npm run preview` — preview the production build
